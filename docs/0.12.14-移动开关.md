# 0.12.14 工具栏「移动/调整」开关

## 问题

调整框（`#adjust`）在开启时会盖住整个模型：它的移动热区 `#adjust-move` 正好压在模型身上，鼠标点下去被当成「拖动窗口」，摸头/点击预设根本没机会触发。设置页里那个「允许调整大小和位置」又是个常驻开关，不开不知道怎么调、开了就点不到模型。

## 改法

1. 顶部工具栏（📌 左边）新增 `✥` 按钮：**移动/调整开关**。
   - 关闭（默认）：调整框完全隐藏，鼠标与模型互动（摸头、点身体、打字、拖动模型无效）。
   - 开启：出现虚线框与 8 个手柄；可以拖边框改大小、拖中间移动窗口。
   - 按钮开启时高亮（蓝底），提示「现在鼠标在操作窗口」。
2. 开关状态落在实例配置 `adjustMode` 里（宿主 `patchInstance` + 写 `config.json`），重开窗口/重启 DSH 后保持上次状态。
3. 调整模式下轻点不拖（位移 ≤6px、≤600ms）仍然算「点模型」：按落点判定 head/body，照常触发预设动作，不会因为开着调整框就摸不到头。

## 代码落点

| 文件 | 改动 |
| --- | --- |
| `electron/index.html` | `#toolbar` 加 `<button id="adjust-toggle">✥</button>`；`#toolbar button.active` 高亮样式 |
| `electron/renderer.js` | `els.adjustToggle`；点击切换 `setAdjustMode()` 并上报 `{type:'adjust-mode', on}`；`setAdjustMode()` 同步按钮高亮；`beginDrag` 记录按下点与时间，`mouseup` 位移 ≤6px 判定为 tap |
| `index.js` | 协议回调新增 `adjust-mode` 分支：`patchInstance({adjustMode})` + 写盘；`patchInstance` 成功后回推 `{type:'config', patch}`，保证多端一致 |

## 验收

1. 完全退出 DSH → 重启 → 关掉旧窗口重新打开（渲染层改动才生效）。
2. 默认状态：鼠标移到模型上，点头顶/身体应能看到动作；不出现虚线框。
3. 点 `✥`：按钮变蓝、出现虚线框；拖边框能改大小、拖中间能移动窗口。
4. 在调整模式开着时，点头顶（不拖动）→ 仍然能摸头。
5. 再点 `✥` 关闭：虚线框消失，鼠标回到模型互动。
6. 关窗重开：`✥` 的开关状态与上次一致（写入 config.json）。

## 已知限制

- 调整框只在模型范围内作为移动热区；窗口边缘 10px 仍留给手柄，避免拖不到边。
- 触摸板/高 DPI 下「6px 内算点击」的阈值可能偏紧，后续可配置。
