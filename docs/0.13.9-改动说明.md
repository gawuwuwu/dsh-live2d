# 0.13.9 改动说明（按你提的四条）

## 1. 动作幅度 / 时间

用户反馈：点头、摇头、眨眼「幅度/时间太小」看不出。改在 `electron/renderer.js` 的 `ANIMS`，并同步放宽宿主的动作兜底超时（`index.js` 的 `handleAnim` / `playPreset`）：2.5s → **4s**，否则动作还没做完就被拉回 idle。

| 动作 | 时长 | 幅度 / 关键帧 |
| --- | --- | --- |
| 点头 nod | 1.4s → **2.2s** | `ParamAngleY` 峰值 -12 → **-20**，保持到 0.6 再回正 |
| 摇头 shake | 1.5s → **2.0s** | `ParamAngleX` ±11 → **±20**（20 → -18 → 16 → -8 → 0） |
| 歪头 tilt | 1.8s → **2.0s** | `ParamAngleZ` 14 → **18**、`ParamAngleX` 6 → 8 |
| 眨眼 blink | 0.4s → **0.9s** | 闭合值 0 → **0.02**（几乎全闭），闭合保持 0.25~0.6（约 0.35s） |

其余表情（happy / shy / surprised / angry / drool / xx / puff）时长不变，仍走 EXP 贴图通道，观感本来就明显。

## 2. 设置页说明里的「旧模式名」

改名后（内部键不变）：`auto` = **手动**、`semi` = **AI 半自动**、`manual` = **AI 自动**。凡是宿主返回给用户的文案都统一到新叫法：

- `modeForbidden()`（`index.js:784`）：`当前是自动模式，对话不能主动…（可在设置页改回手动/半自动）` → **`当前是「手动」模式，AI 不会主动…（想让它主动，可在设置页或窗口模式菜单里切到「AI 半自动 / AI 自动」）`**
- 三条工具失败文案（气泡 / 读屏 / 截图）同样改成「手动模式」+ 新选项名。
- 设置页模式下拉的 hint 已与新叫法一致；模式设置页顶部显示「当前模式：…」。

## 3. 模式依赖的开关：默认开 + 集中管理 + 切换提示

### 默认值
`index.js` 的 `DEFAULT_INSTANCE`：

| 开关 | 旧默认 | 新默认 | 原因 |
| --- | --- | --- | --- |
| `screenReadEnabled`（读屏·前台标题） | false | **true** | 半自动/AI 自动没有它，唤醒不知道你在干什么 |
| `screenCaptureEnabled`（允许截图） | false | **true** | 同上，且唤醒时截图才「看得到」 |
| `aiMoveEnabled`（交给 AI 移动窗口） | false | **true** | 否则「AI 自动」和普通模式没区别 |

隐私说明：截图仍受三重闸门（总开关 / 免确认子开关 / 30s 限速），并在唤醒消息里只附最多 2 张贴图；不想要就关这一项，读屏退化为只读窗口标题。

### 设置页新增「模式设置」tab
位置：设置 → Live2D → 顶部 tab `动作 / 模式设置 / 模型1 / 模型2`。内容：

- 「调整哪个模型」下拉；
- 顶部「**一键开启模式所需开关**」按钮（同时打开读屏标题 + 允许截图 + AI 移动窗口）；
- 三张分组卡：
  - **手动**：读屏·前台标题 / 允许截图 / 点模型有反应 / 空闲小动作；
  - **AI 半自动**：定时唤醒 / 唤醒时截图（间隔与额度提示去「模型 → 主动感知」调）；
  - **AI 自动**：交给 AI 移动窗口。
- 勾选**立即 PATCH 生效**（不用先点保存），并在有开关关闭时显示黄色提示「模式会看起来没区别」。

### 切换模式时的提示
`index.js` 的 `set-mode` 分支：切到「AI 半自动 / AI 自动」时用气泡说明该模式会做什么、是否截图，并列出**未开启的关键开关**（读屏标题 / 允许截图 / 定时唤醒 / 移动窗口）；切到「手动」只说明「不会自己动」。

## 4. 动作循环：统一到「动作」页 + 可绑定两台模型

- **模型页移除**旧的「循环动作 / 每步间隔 / 开始循环」一整块（`client.js` 的「测试与维护」里只留单次试玩与提示）。
- **动作页**的「动作循环」保持唯一入口：
  - 新建循环增加「**绑定模型**」多选（不勾 = 跟随当前模型；最多勾 2 个）；
  - 列表显示「绑定 模型1 + 模型2」；
  - 点「启用」时对每个绑定模型各自启动同一循环。
- 数据结构：`presetSequences[].targets: string[]`（`normalizePresetSequences` 校验，最多 2 个、id 规则 `^[\w-]{1,32}$`）。

## 验证步骤

1. 完全退出 DSH → 重启（宿主代码改了）。
2. 设置页刷新一次（页面级 JS），确认顶部出现「模式设置」tab。
3. 模式设置 → 点「一键开启模式所需开关」→ 三个开关变勾选（存量 `config.json` 里是 false，靠这一步或逐项勾选打开）。
4. 动作页 → 点「点头」：应明显低头约 2 秒；「摇头」左右各一次；「眨眼」能看到闭眼约 0.35 秒。
5. 动作页 → 新建循环 → 勾两个动作 + 勾「绑定模型」两项 → 保存 → 启用：两台模型应同步循环。
6. 窗口工具栏切模式：应弹气泡说明该模式能力与未开开关。

## 已知限制

- **存量配置**：默认值只对「没有 config.json / 新建实例」生效；你机器上已有的 `config.json` 仍是旧值，需要在「模式设置」点一次「一键开启」（或逐项勾选）。这是为了避免把用户主动关掉的开关在重启时又打开。
- 动作仍是 3 秒冷却（`animCooldownMs`），连点会 429。
- 循环绑定的是实例 id；删掉某个模型后，循环里那一项会失效，需要重新保存绑定的循环。
