# 0.12.18 截图工具化（读屏闭环）

0.11.0 已经有截图能力（`requestScreenCapture` + `electron/capture.ps1`），但只有 HTTP 接口——AI 在对话里拿不到图，读屏等于没闭环。本版补上工具层。

## 1. 新工具 `live2d_screen_capture`

| 参数 | 说明 |
| --- | --- |
| `instanceId` | 可选，默认当前会话绑定的实例 |
| `confirm` | 用户已同意这次截图；开了「截图免确认」可省略 |

返回：

```json
{ "ok": true, "summary": "instanceId=inst-2 path=C:\\Users\\...\\Temp\\dsh-live2d-screens\\shot-2026-11-04T14-20-00-000Z.png width=2560 height=1440 bytes=6712345 at=... hint=用 read_image 打开 path 查看这张截图" }
```

AI 拿到 `path` 后用 `read_image` 打开，就真正“看见”屏幕了。

## 2. 隐私闸门（沿用 0.11.x，未放宽）

1. **总开关**：`screenCaptureEnabled`（默认关）。没开 → `screen-capture-disabled`，不截图。
2. **确认闸**：`screenCaptureAutoConfirm`（默认关）。没开时必须先问用户，带 `confirm:true` 才截；否则回 `needs-confirm`。
3. **限速**：`screenCaptureIntervalMs`（默认 30s，范围 5~300s）。频繁调用 → 429 语义，带 `retryAfterMs`。
4. **并发闸**：`screen.inFlight` 先占位再 await，两个并发只放一个。
5. **模式闸**：`auto` 模式一律拒绝（`mode-forbidden`）。
6. **归属闸**：`resolveToolTarget` 要求实例绑定到当前会话，不能跨会话偷看别的实例。

## 3. 落盘策略

- 目录：`os.tmpdir()/dsh-live2d-screens`（系统临时目录，不在用户文档/配置里）。
- 文件名：`shot-<ISO 时间>.png`。
- 只保留最近 10 张（`pruneCaptureDir`），超出按 mtime 删最旧。
- 截图内容不写入记忆、不进日志（只记尺寸/字节数/时间）。

## 4. 验收

单测（`tests/shell.mjs`）：

- `截图工具：未开允许截图时拒绝`
- `截图工具：没确认时要求先问`
- `截图落盘：写出 PNG 文件`
- `截图落盘：只保留最近 10 张`

真机闭环（重启 DSH 后）：

1. 设置页开「允许截图」，可选开「截图免确认」；
2. 让 AI 说「看一眼我的屏幕」→ 它应先问一句（或直接截，看免确认开关）；
3. 工具返回 `path`，AI 用 `read_image` 打开并向你描述屏幕内容。

## 5. 已知限制

- 只有全屏截图，没有窗口级截图（要窗口级得用 desktopCapturer，需独立 Electron 通道）。
- 截图是整屏，可能包含别的窗口；确认闸就是为这个留的。
- 临时目录不会主动清空，靠「最近 10 张」和系统临时目录策略。
