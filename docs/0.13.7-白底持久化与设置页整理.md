# 0.13.7 · 白底持久化与设置页整理

## 白底为什么在 0.13.5/0.13.6 后仍会出现

窗口主进程会在 ready 时夹取坐标，但设置页草稿保存的是整份配置，其中包含打开页面时读到的旧 `windowX/windowY`。只要之后保存任意无关设置，旧坐标就可能重新写回 `config.json`；下次开窗再次越界。

另外，透明窗口在未聚焦、跨显示器或显示器 DPI 边界附近时，Windows 合成器可能延迟重绘透明区域，表现为白色矩形，切换前台窗口后才恢复。

## 修复

- 设置页普通保存不再提交未主动修改的 `windowX/windowY`。
- 增加「改为自动摆放」，可显式清空坐标。
- 主进程保存 `entry.config`，`init`/`config` 的局部几何 patch 先合并再夹取，不会回落到 320×420。
- 创建、初始化和所有几何更新统一经过同一工作区夹取函数。
- 透明窗口在 ready、show、focus、blur、move、resize 后执行背景重置、Chromium invalidate 和一次 PIXI 重绘。
- 设置页模型表单增加基础信息、窗口与模型、对话与气泡、主动感知、语音、测试与维护分组。
- 字段改为两列网格，长说明默认折叠；实例顶部增加保存和打开/关闭窗口操作。

## 验收

1. 重启 DSH 后打开模型 1，白底应立即消失，不需要切换界面。
2. 读取 `/live2d/window?instanceId=inst-1`，bounds 应在某块显示器工作区内。
3. 修改并保存任意无关设置，再重启，确认 `windowX/windowY` 不会回到旧的越界值。
4. 在模型窗口与 DSH 之间来回切换、拖动跨屏、修改显示缩放，不应再出现白底。
