# 0.13.1 · 模式下拉菜单 + 模型区穿透

## 1. 模式按钮改成下拉菜单

- 之前：`#mode-cycle` 点击循环 `手动 → 半自动 → 自动`，容易点过头。
- 现在：点击展开 `#mode-menu` 浮层，三个选项带当前项 `✓`，点选即切换并关闭；点菜单外区域也关闭。
- 菜单打开期间强制关闭穿透（`setIgnore(false)`），所以穿透状态下也能点菜单。
- 按钮文案：`手动 ▾ / 半自动 ▾ / 自动 ▾`，仍是 `active` 高亮（非手动）。
- 菜单挂着 `debug-menu` 命令（只有宿主能发），供探针截图验证。

## 2. 模型遮挡（置顶时点不到下面的窗口）

两种解法，互补：

| 办法 | 做法 | 效果 | 代价 |
| --- | --- | --- | --- |
| 取消置顶 | 点工具栏 📌 | 窗口回到普通层，会被其他窗口盖住 | 模型可能被别的窗口挡住 |
| 模型区穿透（新） | 设置页实例卡片勾「模型区也穿透」（`modelPassthrough`） | 工具栏/输入栏/气泡仍可点，**模型身体不再拦鼠标**，点得穿到下面 | 此时摸不到模型（tap 收不到），取消勾选即恢复 |

实现：`isInteractiveAt()` 在 `settings.modelPassthrough === true` 时跳过 `model.getBounds()` 命中，只保留 UI 元素（`#toolbar / #composer / #reply / #adjust / #mode-menu / #preset-menu` 等）。穿透判定仍由主进程 150ms `pointer-probe` 兜底，不受 `forward:true` 可靠性影响。

配置：`DEFAULT_INSTANCE.modelPassthrough = false`，走 `boolOr` 校验、`INSTANCE_KEYS`、`windowConfigPayload`，改设置页开关会回推 `config` 立即生效，无需重开窗口。

## 3. 验证

- `node tests/shell.mjs` / `node tests/client.mjs` 全过。
- 探针 `.tmp/mode-menu-probe.mjs`：`debug-menu` 打开模式菜单后截图，三个选项与 `✓ 半自动` 显示正常（`.tmp/mode-menu.png`）。
- 穿透开关为行为项，需真机：勾选后在模型身上点击，事件应落到下层窗口；取消后恢复摸头。

## 4. 已知限制

- 穿透开启时，模型区域的「摸头/戳一下」失效（这是穿透的必然结果）；
- 穿透仍要求工具栏可见（工具栏本身一直在最上层，未受穿透影响）。
