# 0.13.3 · 设置页 tab 化 + 动作管理 + 默认模式修正

## 1. 默认模式显示修正

- 现象：模式下拉默认显示「AI 自动」（用户明确要求默认应为「手动」）。
- 原因：`client.js` 的 `toDraft()` 里回落值仍是旧写法
  `config.mode === 'auto' || config.mode === 'semi' ? config.mode : 'manual'`，
  配置缺 `mode` 时落到 `manual`（显示名「AI 自动」）。
- 修正：回落值改为 `'auto'`（显示名「手动」）；下拉顺序改为 **手动 / AI 半自动 / AI 自动**（从静到动）。

## 2. 设置页 tab 化

顶部三个 tab：**动作 / 模型1 / 模型2**。

### 动作页

- **应用到哪个模型**：选择动作/循环作用在模型 1 还是模型 2（显示「已绑定 / 未绑定 / 已停用」）。
- **默认动作**：11 个内置动作按钮（与宿主 `ANIM_WHITELIST` 对齐），点一下立刻播。
- **自定义动作**：已有的自定义动作也会列出来，可点播。
- **新增动作**：
  1. 「动作名」+「动作说明」（一句话描述想要的动作/情绪）；
  2. 点「生成」→ 宿主 `POST /live2d/preset {op:'design'}` 返回草稿（8 个情绪模板：开心/难过/生气/惊讶/害羞/困倦/思考/招手；没有命中就用通用摆动）；
  3. 点「预览」→ `{op:'preview'}` 直接把草稿关键帧塞给窗口播一遍（不落盘）；
  4. 点「保存动作」→ `PATCH /live2d/instances/:id {customActions}`，之后右键菜单和 AI 工具都能用。
- **动作循环**：
  - 列出当前实例的 `presetSequences`（名称 / 步数 / 间隔），每条有「启用」；
  - 「停止循环」一键停；
  - 「新建循环」：名称 + 勾选动作（内置 + 自定义）+ 间隔秒（0.3~60）→ 保存到 `presetSequences`。

### 模型 1 / 模型 2 页

- 上限固定 2 个，**取消「新增对话」卡片**；模型 2 未创建时，该 tab 内显示「启用模型 2」（选模型 + 可选绑定会话）。
- 新增**启用模型**开关（`enabled`）：
  - 关闭后不自动开窗、不参与定时唤醒 / 空闲动作 / 定时读屏；
  - 配置保留，随时开回来；
  - 宿主侧 `DEFAULT_INSTANCE.enabled = true`，`INSTANCE_KEYS`、`INSTANCE_PERSISTED`、`windowConfigPayload` 同步；
  - `startWakeLoop` / `startPresetLoop` / `screenWatchTick` / 自动开窗四处都会跳过停用实例。
- 模型内其余设置保持原样，只是从「一串卡片」变成「每模型一页」。

## 3. AI 主动设计动作

- `live2d_preset` 工具描述补一句：没有合适现成动作时应自己 `define` 新动作再 `play`，别硬套不贴切的预设。
- 唤醒消息（`buildWakeMessage`）在允许做动作的模式下追加可执行示例：
  `live2d_preset {op:"define", ... tracks:[{param:"headZ", keys:[[0,0],[0.3,12],[0.85,10],[1,0]]}]}` + `{op:"play"}`，
  并说明逻辑参数名（headX/headY/headZ/eyeOpenL/eyeOpenR/eyeBallX/eyeBallY/mouthOpen/mouthForm/bodyX）与「缺参数自动跳过」。
- 设置页的「生成」是模板启发式；更细的动作由 AI 在对话里用 `live2d_preset define` 设计（两者都写到同一份 `customActions`）。

## 5. 已知限制

- 「生成」只覆盖 8 类情绪模板，复杂动作精度有限（可改说明重试，或让 AI 设计）；
- 循环的启停是即时命令，不持久化「正在运行」状态（重启后需重新点启用）。
