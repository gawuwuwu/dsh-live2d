# 0.12.15 表情扩展（angry / drool / xx / puff）

## 背景

模型的 `.cdi3.json` 里除了动作参数，还有一组专属表情参数（EXP 系列），每个都带自己的贴图，观感比单纯调 `Param*` 明显得多：

| 参数 | 含义 |
| --- | --- |
| `PARAM_EXP1` | 口型切换 |
| `PARAM_EXP2` | 龇牙 |
| `PARAM_EXP3` | 脸黑 |
| `PARAM_EXP4` | 脸红（`shy` 已在用） |
| `PARAM_EXP5` | >v< / O_O（`surprised` 在用） |
| `PARAM_EXP6` | X X 眼 |
| `PARAM_EXP7` | 流口水 |
| `PARAM_EXP8` | 栗子嘴 |

## 新增动作

| action | 时长 | 用到的参数 | 观感 |
| --- | --- | --- | --- |
| `angry` | 2400ms | `PARAM_EXP3` + `ParamEyeAnger` + 低头 + 抿嘴 | 脸黑、生气 |
| `drool` | 2600ms | `PARAM_EXP7` + 低头 | 流口水/傻笑 |
| `xx` | 1400ms | `PARAM_EXP6` + 歪头 | X X 眼（无语/崩溃） |
| `puff` | 2200ms | `PARAM_EXP8` + 抿嘴 | 栗子嘴 |

白名单从 8 个扩到 **12 个**：`idle / nod / shake / tilt / happy / shy / surprised / blink / angry / drool / xx / puff`。

## 别名

外部（AI/设置页）可以用更自然的词：

- `blush`、`embarrassed` → `shy`
- `stare` → `xx`

宿主 `handleAnim` 先归一别名再走白名单，返回体里的 `action` 是归一后的真实动作名；渲染层也保留一份兜底映射，避免旧缓存命令失效。

## 设置页

实例卡片底部新增「试玩」按钮组：`nod / tilt / happy / shy / surprised / angry / drool / xx / puff`，点一下就发 `/live2d/anim`，不用等 AI 发指令。

## 验证

- 单测：`动作别名 blush → shy`、`表情扩展四个可用（angry:200,drool:200,xx:200,puff:200）`。
- 探针（640×840，副本模型）裁脸对比：脸黑、张眼笑、X 眼、栗子嘴四种观感都成立。
- 与既有动作共用同一条参数关键帧通道：一次只播一个（`animState` 单例），不会叠加。

## 已知限制

- EXP 参数是「整张贴图」，同一时刻只能有一个；`shy`/`surprised`/`angry`/`drool`/`xx`/`puff` 互斥，连发会顶掉上一个。
- `angry` 的「脸黑」是整脸压暗，和「生气」语义接近；如果只想要皱眉可以用 `ParamAngleZ` + `ParamEyeAnger`，目前没拆。
- 动作仍受 3 秒冷却约束（`animCooldownMs`），试玩连点第二下会 429。
