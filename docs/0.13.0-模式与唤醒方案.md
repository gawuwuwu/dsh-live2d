## 2. 新语义：三种模式的行为矩阵

| 行为 | 自动 | AI 半自动 | AI 手动 |
| --- | --- | --- | --- |
| 空闲动作循环（眨眼/歪头） | ✓ | ✓ | ✓ |
| 摸头 / 戳一下有反应 | ✓ | ✓ | ✓ |
| **用户点「主动唤醒」** → 截图（无截图权限则读标题）+ 回复 | ✓（一次性） | ✓ | ✓ |
| **定时唤醒**（默认 30s，可调） | ✗ | ✓ | ✓ |
| 唤醒前截图（与唤醒同频） | 仅按钮触发时 | ✓ | ✓ |
| AI 主动动作 / 推气泡 | ✗ | ✓ | ✓ |
| AI 自主移动 / 缩放模型 | ✗ | ✗ | ✓ |
| 读屏（标题/截图） | 按钮唤醒时临时放行 | ✓ | ✓ |

要点：

- **「唤醒」= 生成一条新回复**（向会话注入一条消息）；「推气泡」= 把已有回复显示出来。两者分开管。
- auto 的「不唤醒 AI」包含：不推自动气泡、不定时唤醒；但**用户点按钮**属于用户主动，允许一次截图 + 回复。
- semi 与 manual 的差别只有一个：manual 允许 AI 动窗口（移动/缩放，包括「挡屏幕」）。其余完全一致。

## 3. 唤醒流程

```
触发（按钮 / 定时器）
  ├─ 解析实例 + 会话（严格；未绑定 → 提示去设置页，不回落默认实例）
  ├─ 模式闸：auto 只允许 source='button'
  ├─ 忙检查：agent.status === 'running' 或 chat.inFlight
  │    ├─ 忙 → 先截图（若允许）存 pendingShots（上限 2，丢最旧）
  │    │        └─ 返回 skipped:'busy'，不注入消息
  │    └─ 闲 → 继续
  ├─ 截图闸：wakeCaptureEnabled + screenCaptureEnabled + 限速（screenCaptureIntervalMs）
  │    ├─ 允许 → CopyFromScreen → 临时 PNG（只留 10 张）
  │    └─ 不允许 → 读前台窗口标题（标题层）
  ├─ 组装消息（≤500 字）：
  │    [Live2D 主动唤醒] 现在 <HH:mm>，你在 <mode> 模式。
  │    前台：<title>（<process>）
  │    截图：<path1>（用 read_image 看）
  │    待看的旧截图：<path2>（上次你忙没看）
  │    请：一句观察 + 一句带情绪价值的回应；不要长篇。
  │    （可调用 live2d_anim / live2d_bubble）
  └─ agent.followup(msg).catch(...)  ← 必须接住 rejection（历史事故：未接住会让宿主退出）
```

回复回流：

- `agent/status → idle` 时，取该会话最后一条 assistant 文本 → 推窗口气泡（`pushIdleReplies` 改造：按实例模式判断，manual 也允许）。
- `wakeAutoSpeak` 开着时走 `speakForReply`（TTS + 口型），与现有同步协议复用。
- 台账写 `inst.wake = { lastAt, lastSource, lastPath, skipped, pending: [...], replyAt, replyPreview }`，health/diag 暴露。

### 忙时「下次带 2 张」的细节

- `pendingShots` 是**按实例**的环形队列，元素 `{ path, at, title, process }`，上限 `wakePendingShots`（默认 2）。
- 只有「定时唤醒被跳过」才入队；按钮触发被跳过时也入队（下次一并看），并当场返回 `busy` 提示。
- 成功唤醒后清空队列（消息里已带路径）。

## 4. UI 改动（窗口工具栏）

```
[✥] [模式: 自动 ▾] [⚡] [📌] [×]
```

- `#mode`：点击循环 manual → semi → auto（或弹 3 项小菜单；建议菜单，避免误切）。
  - 显示：`自动` / `AI半自动` / `AI手动`；颜色：灰 / 蓝 / 紫。
  - 切换 → `report({ type:'mode', mode })` → 宿主 `patchInstance({ mode })` + 写盘 + 回推 `config`。
- `#wake`（⚡）：
  - 点击 → `report({ type:'wake', source:'button' })`。
  - 处理中显示 `…`（禁用）；返回后短暂显示结果（`✓` / `忙` / `未绑定`），2s 恢复。
  - 未绑定会话时提示「先在设置页绑定会话」。
- 两个按钮都在 hover 工具栏里，不占模型点击区；adjust 模式下仍可点（z-index 30）。

## 6. 参数表（新增，默认值可调）

| 参数 | 默认 | 范围 | 越界处理 |
| --- | --- | --- | --- |
| `wakeEnabled` | `false`（semi/manual 可开） | bool | — |
| `wakeIntervalMs` | `30000` | 15000~300000 | 回落 30s + 告警 |
| `wakeCaptureEnabled` | `true` | bool | —（关闭则只读标题） |
| `wakePendingShots` | `2` | 1~5 | 回落 2 + 告警 |
| `wakeAutoSpeak` | `false` | bool | —（复用 TTS） |
| `wakeMaxPerHour` | `60` | 10~300 | 回落 60 + 告警（成本保护） |
| `aiMoveEnabled` | `true`（仅 manual 生效） | bool | — |

`screenCaptureIntervalMs` 继续作为截图限速（默认 30s），`wakeIntervalMs` 与它独立：唤醒间隔到了但截图被限速 → 本次只读标题，不阻塞唤醒。

## 8. 风险与取舍（需要你拍板）

1. **成本**：30s 一次 = 每小时最多 120 次唤醒，每次都带一张截图（图像 token 大）。方案里加了 `wakeMaxPerHour: 60` 保护，默认仍按你说的 30s。
2. **会话污染**：唤醒必须向绑定会话注入一条 user 消息（agent 只能这样产生回复），所以对话历史里会多出「[Live2D 主动唤醒]…」+ AI 回复。缓解：消息带 `source.kind='live2d-wake'`，面板可过滤；若你希望「不进主对话」，唯一替代是给每个实例开一个隐藏会话（成本更高、上下文割裂），需要你确认。
3. **截图隐私**：semi/manual 定时截图是自动的，仍受「允许截图」总开关 + 30s 限速 + 只留 10 张。建议定时唤醒默认**只读标题**，截图单独开关（`wakeCaptureEnabled` 默认 false 更稳，方案先写 true，等你定）。
4. **auto 语义变化**会关掉现有「自动上气泡」，属于行为回退，需要你确认（我理解这就是你要的）。

## 9. 验收清单

1. 工具栏出现「模式」「⚡」两个按钮，点击模式循环且设置页同步。
2. auto：不推气泡、不定时唤醒；点 ⚡ → 截图（或标题）+ AI 回复一次。
3. semi：30s 唤醒一次，截图与唤醒同频；AI 回复同时带表情。
4. 上一条没答完时唤醒 → 跳过并截图；下一次唤醒消息里出现 2 张路径。
5. manual：除 semi 外，AI 能 `live2d_window op:move/scale` 移动放大窗口（含挡屏幕）。
6. 忙时按钮点击给出「正在回答，稍后」反馈。
7. 未绑定会话时所有唤醒路径都明确提示，不回落默认实例。
