# 0.12.9 气泡布局：左右调模型 / 上下调气泡 / 固定气泡大小

## 需求（用户原话要点，2026-11-04）

> 现在调整框过小会将模型挤扁。需求的功能为模型正常比例，调整框左右调整会调整模型大小（上半部分留空，为气泡部分），上下调整会调整气泡大小。将模型/气泡比例改为气泡实际大小，通过刷新坐标按钮也会刷新目前气泡大小数值。增加一个固定气泡大小按钮（默认关），关闭时气泡大小为设置中填入的固定值（此时上下调整调整框失效，气泡高度不会随调整框变化而变化）。

## 布局规则

| 操作 | 结果 |
| --- | --- |
| 左右拖调整框（改窗口宽） | 模型等比放大/缩小（`scale = 窗口宽 / 模型宽 × 0.96 × 模型缩放%`），永不变形 |
| 上下拖调整框（改窗口高） | 气泡变高/变矮（气泡 = 窗口高 − 输入栏 52 − 模型实际高 − 6） |
| 勾选「固定气泡大小」 | 气泡锁死为设置里的 px 值；上下拖只改变窗口，不改气泡（模型按剩余空间缩放） |

- 模型贴底站（脚底在输入栏上方），气泡从模型头顶向上长 → **两者不重叠**，气泡变大不会压住角色。
- `zoom-overlay` 布局模式例外：允许气泡覆盖模型（底边固定在输入栏上方）。
- 模型放大到超出窗口时由 canvas 裁切，不做二次缩放（保持等比）。

## 参数

| 参数 | 默认 | 范围 | 说明 |
| --- | --- | --- | --- |
| `bubbleFixedSize` | `false` | 布尔 | 固定气泡大小开关；越界/非布尔回落 false 并告警 |
| `bubbleHeightPx` | `200` | 80~900（px） | 固定模式下的气泡高度 |
| `replyFontSize` | `15` | 12~24（px） | 气泡字号 |
| `modelScalePct` | `100` | 50~200（%） | 模型在「宽度适配」基础上的额外缩放 |

## 设置页

- 「字号 / 气泡高度」一行：字号 px、**实际气泡 `<n>px`**（读窗口上报的 `renderer.layout.bubblePx`）、「固定气泡大小」复选框、固定高度 px 输入（仅勾选时可用）。
- 「刷新坐标」会同时刷新窗口几何与气泡实际大小。

## 数据流

```
拖调整框 → main.cjs setBounds → 窗口 resize → renderer.fitModel()
  → 计算 scale / bubblePx / model.y → report({phase:'layout', bubblePx, modelPx})
  → applyReplyStyle() 写 --reply-max-height → #reply 按它滚动
  → 宿主 applyWindowMessage 存 state.renderer.layout → /live2d/instances / diag 暴露
  → 设置页「刷新坐标」读取显示
```

## 验收步骤

1. 重启 DSH，关掉旧窗口重开（渲染层改动必须重开窗口）。
2. 拖动调整框**左右**：模型等比变大变小，脸/身体不变形，气泡高度基本不变。
3. 拖动调整框**上下**：气泡变高/变矮，模型大小不变，气泡始终在模型头顶上方。
4. 勾选「固定气泡大小」并填 200：再上下拖，气泡高度不再变化；取消勾选恢复联动。
5. 点「刷新坐标」：窗口宽高与「实际气泡」像素同步更新。

## 已知限制

- 窗口很窄时模型按宽度会超出高度上限，自动收缩（等比），此时上下拖动同时影响模型可用高度。
- 「实际气泡」显示的是窗口上一次上报的值；窗口未打开或刚改完未保存时显示 `—`。
- 渲染层改动不重启 DSH 不会生效；只改 `index.js` 也必须重启宿主。
