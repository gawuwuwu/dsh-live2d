# 0.1.5 · Cubism 4.2 颜色兼容与工具栏

## 鼻尖黑块

### 根因

`pixi-live2d-display@0.4.0` 的 Core 数据对象已经包含：

- `drawables.multiplyColors`
- `drawables.screenColors`

但 0.4.0 的 WebGL 渲染器没有把这两组颜色上传到 shader，也没有在 fragment shader 中应用。

新模型鼻部两个 drawable：

- `ArtMesh246`
- `ArtMesh682`

均为：

- `MultiplyColor = (0, 0, 0, 1)`
- `ScreenColor = (1, 0.964705884, 0.960784316, 1)`

隐藏这两个 drawable 后，黑块立即消失；说明黑块来自 Cubism 4.2 颜色特性兼容缺口，不是纹理上传失败或模型损坏。

### 修复

新增 `electron/assets/vendor/cubism4-color-compat.js`，在 pld 0.4 的 shader 层补齐：

- Normal / Additive / Multiplicative
- Masked / Inverted Masked
- 每 drawable 的 `u_multiplyColor`
- 每 drawable 的 `u_screenColor`

颜色公式按预乘 Alpha 处理：

```glsl
color.rgb = color.rgb * multiply.rgb;
color.rgb = color.rgb + screen.rgb * color.a - color.rgb * screen.rgb;
```

## 顶部工具栏

工具栏不再完全透明隐藏，而是以 62% 透明度常显，鼠标悬停恢复 100%。这样模型区穿透、窗口失焦或指针探测短暂失效时，仍能看到并找到固定、模式和关闭按钮。

## 验证

- 同一模型在干净探针中：修复前鼻尖黑块存在；修复后黑块消失。
- 原有模型 multiply=white / screen=black，兼容层不会改变外观。
- 模型 1 / 模型 2 的顶部工具栏都应常显低透明度按钮。
